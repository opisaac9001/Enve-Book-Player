# Reader font provenance

Literata, Atkinson Hyperlegible Next, and Lexend are copied from the Google Fonts repository at commit `334b789e33413f3aba4264d9aa6c97f7b94c5a2f`.

| Bundled file | Upstream path |
|---|---|
| `app/src/main/assets/reader-fonts/Literata.ttf` | `ofl/literata/Literata[opsz,wght].ttf` |
| `app/src/main/assets/reader-fonts/Literata-Italic.ttf` | `ofl/literata/Literata-Italic[opsz,wght].ttf` |
| `app/src/main/assets/reader-fonts/AtkinsonHyperlegible.ttf` | `ofl/atkinsonhyperlegiblenext/AtkinsonHyperlegibleNext[wght].ttf` |
| `app/src/main/assets/reader-fonts/AtkinsonHyperlegible-Italic.ttf` | `ofl/atkinsonhyperlegiblenext/AtkinsonHyperlegibleNext-Italic[wght].ttf` |
| `app/src/main/assets/reader-fonts/Lexend.ttf` | `ofl/lexend/Lexend[wght].ttf` |

The app also exposes the OpenDyslexic and iA Writer Duospace files already distributed by Readium Kotlin Toolkit 3.3.0 to the Foliate reader. Those files remain at `readium/fonts/OpenDyslexic-Regular.otf` and `readium/readium-css/fonts/iAWriterDuospace-Regular.ttf` in the Readium Navigator AAR.

All reader fonts are unmodified and retain their upstream names and SIL Open Font License terms. File digests are recorded in `SHA256SUMS`.
