# Getting Help

Choose the place that best matches what you need:

| Need | Where to go |
| --- | --- |
| A reproducible app bug | [Open a bug report](https://github.com/opisaac9001/Enve-Book-Player/issues/new?template=bug_report.yml) |
| A source-code feature proposal | [Open a feature request](https://github.com/opisaac9001/Enve-Book-Player/issues/new?template=feature_request.yml) |
| Setup or server help | [Enve Support](https://github.com/opisaac9001/Enve-Support/issues) |
| A general question | [Discord](https://discord.gg/Hw4nmXRehb) |
| Guides and common answers | [Documentation](https://envemedia.com/docs/) and [FAQ](https://envemedia.com/faq.html) |
| A security vulnerability | Follow [SECURITY.md](SECURITY.md) |

Before posting, remove passwords, access tokens, private server addresses, personal media details, and unredacted diagnostic data.
